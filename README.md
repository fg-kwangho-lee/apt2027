# apt2027 — 전국 아파트 입주물량 · 매출 대시보드

빌드 단계가 없는 정적 웹사이트입니다. `Dockerfile`(nginx)로 사내 서버에 단일 컨테이너로 배포합니다.

## 화면

| 파일 | 내용 |
|---|---|
| `index.html` | 전국 아파트 입주물량 (2026~2030) |
| `dashboard.html` | 매장 매출 대시보드 |
| `hq-dashboard.html` | 본부 대시보드 |
| `itemlist_2026_08/index.html` | 아이템리스트 QR 페이지 |

## 접근 제한 (중요)

`dashboard.html` 에는 **인증 기능이 없습니다.** 접근 제한은 **사내 서버 접근통제(사내망 / 로그인 프록시)** 로 처리합니다.

- 예전에는 매장별 비밀번호가 이 파일 안에 직접 적혀 있었으나, 정적 HTML 은 브라우저에서 소스보기로 누구나 읽을 수 있어 **전부 제거**했습니다. 비밀번호를 다시 넣지 마세요(별도 `.json`·`.env` 파일로 옮기는 것도 같은 이유로 안 됩니다 — 브라우저가 그 파일도 그대로 내려받습니다).
- **이미 코드에 노출됐던 매장 비밀번호는 그대로 재사용하지 말고 교체해 주세요.**

## 데이터 출처

`dashboard.html` 은 Google 스프레드시트를 브라우저에서 직접 읽습니다. 따라서 해당 시트가 "링크가 있는 모든 사용자" 공개로 설정돼 있어야 화면이 뜹니다 — **사내 매출 원본이 인터넷에 열려 있다는 뜻이므로 공유 설정을 반드시 확인**하세요. 장기적으로는 서버(백엔드)를 두고 브라우저가 사내 API 만 호출하도록 바꾸는 것을 권장합니다.

## 로컬 도구 (컨테이너에 포함되지 않음)

수집·가공·업로드 스크립트(`*.js`, `*.mjs`, `*.py`, `scripts/`)는 내 PC에서만 실행하며 `.dockerignore` 로 배포 이미지에서 제외됩니다.

| 설정값 | 쓰는 곳 |
|---|---|
| `GITHUB_TOKEN` | `upload_gist.js` — 내 PC에서 수동 실행 |
| `SLACK_WEBHOOK_URL` | `news-clipping.mjs` — GitHub Actions 에서만 사용 |

## 로컬 확인

```bash
npx serve .          # 또는
docker build -t apt2027 . && docker run --rm -p 8080:80 apt2027
```
